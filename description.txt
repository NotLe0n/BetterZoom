[c/FFE900:                                How to use:]
_________________________

[c/FFE900:In Settings:]
Clicking on the Zoom or UIScale text next to the sliders will reset the value to 100%.
You can toggle between slider and exact input using the toggle button next to the header text "Zoom".
The text box only takes numbers from 0 to 1000 and pressing the Enter key or clicking away will submit the change.

Zoom:
[c/C4C4C4:    Changing the Zoom slider or Pressing the]
[c/C4C4C4:    plus or minus keys on your keyboard]
[c/C4C4C4:    (not the ones on the numpad) will zoom your]
[c/C4C4C4:    game in and out just like normal, but]
[c/C4C4C4:    instead of zooming from 100% to 200%,]
[c/C4C4C4:    you can zoom from 10% to 5000%.]
[c/C4C4C4:    How big the slider is can be changed in the Config]

[c/FF0000:    Warning the more you zoom out the laggier it gets!]
    You can disable rendering tile in the Config if it's too much

UI Scale: 
[c/C4C4C4:    You can change the UI Scale from 50% to 500%.]
[c/C4C4C4:    You can also change this by holding shift while]
[c/C4C4C4:    pressing plus or minus.]

If you cannot for whatever reason change the Zoom or UI Scale in game, you can change the "Zoom" and "UIScale" values inside the configuration file located at "Documents/My Games/Terraria/tModLoader/config.json" while the game is closed.

[c/FFE900:Mod Config:]
Background Scale (default: 'off'):
[c/C4C4C4:    This toggles if the background should zoom too.]

Cursor Scale (default: 1x):
[c/C4C4C4:    This changes the size of your cursor.]

Zoom Range (default: 30% - 1000%):
[c/C4C4C4:    This changes the maximum and minimum amount of zoom you can set.]

UI Scale Range (default: 50% - 500%):
[c/C4C4C4:    This changes the maximum and minimum amount of UI scale you can set.]

Disable UI Zoom Hotkey (default: 'off'):
[c/C4C4C4:    Disables the Shift+Plus/Shift+Minus Hotkey to change the UI zoom.]

Render more tiles (default: 'on'):
[c/C4C4C4:    Turning this on renders more tiles outside the normal view range.]
    Note: This will make the game noticeably laggier the more you zoom out.
    I can't do anything about that.
    
Tile render limit (default: 1.0):
[c/C4C4C4:    This sets at which zoom level you can see more tiles.]
[c/C4C4C4:    The lower it is, the laggier the game but the more tiles you can see.]
    For example if you set this to 0.5 (50%) you can see tiles up to 50% zoom.

Zoom Speed (default: 1.0):
[c/C4C4C4:    Changes how fast you zoom in using the keyboard.]
    1 is normal speed, 10 is 10x faster.
